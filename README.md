# НМТ математика — фронтенд

Тренажер [НМТ-2026](https://github.com/tony-kobs/nmt-test-frontend) з математики за структурою УЦОЯО і практика за тими самими темами й завданнями. Бекенду немає: банк, сесії й історія живуть у браузері.

## Що вміє застосунок

| Розділ | Маршрут | Зміст |
| --- | --- | --- |
| Welcome | `/` | Привітання, навіщо тренуватись, перехід у тренажер або практику |
| Тренажер НМТ | `/nmt` | Повний тест, слабкі теми, випадковий варіант |
| Практика | `/practice` | 6 тем НМТ: звичайний режим або Ultimate |
| Формули | `/nmt/formulas` | Довідник алгебри й геометрії (KaTeX) |
| Результати | `/nmt/results` | Історія спроб |

### Тренажер НМТ

- **10 фіксованих варіантів** по **22 завдання**, таймер **60 хвилин**, максимум **32 тестові бали**.
- Вибір конкретного варіанта або випадкового (спочатку з непройдених).
- Типи: одна відповідь, відповідність (часткові бали за пари), коротка відповідь.
- «Слабкі теми» ведуть на `/practice?topic=…` з найгіршою категорією після першого повного НМТ.
- Історія, позначка завдання, повтор усього тесту або одного питання.
- Сесія й результат зберігаються через Redux Persist (не зникають після F5).

### Практика

- Ті самі **220 завдань** банку, згруповані в **6 тем** НМТ.
- **Звичайний** — розбір після кожного завдання; кнопка «Далі» у полі тесту.
- **Ultimate** — до **20** випадкових завдань з теми, **20 хвилин**, без підказок, розбір у кінці.
- Під час сесії: виділений бейдж режиму, таймер (Ultimate), кнопка **Завершити тестування** з підтвердженням → назад до вибору теми.
- Відповідність: перевірка лише після заповнення всіх пар; селекти блокуються після відповіді.

### UI

- Стиль зошита в клітинку, світла/темна тема.
- Перемикач теми в шапці — світчер з іконками сонця й місяця.
- Брейкпоінти: 320 / 768 / 1280.

## Оцінювання НМТ-2026

Схема як у характеристиці сертифікаційної роботи УЦОЯО (математика, 2026).

| Тип | Кількість | Бали | Разом |
| --- | --- | --- | --- |
| Вибір однієї відповіді | 15 | 0 або 1 | 15 |
| Відповідність (3 пари → А–Д) | 3 | 0–3 (1 за пару) | 9 |
| Коротка відповідь | 4 | 0 або 2 | 8 |
| **Усього** | **22** | | **32** |

У відповідностях літера не повторюється: повтор стовпчика не дає бала. Рейтинг **100–200** — лише для повного тесту (поріг **5** тестових балів → 100, **32** → 200).

## SEO

- Метадані Open Graph / Twitter, canonical, `lang="uk"`.
- `robots.txt` і `sitemap.xml` (App Router).
- JSON-LD (`WebSite` + `WebApplication`) на головній.
- Сторінка активної спроби `/nmt/test` — `noindex`.
- Favicon (`/favicon.svg`) і OG-картинка (`/og.png`).

У продакшені канонічний домен уже заданий:

```bash
NEXT_PUBLIC_SITE_URL=https://nmt-test-frontend.vercel.app
```

Локально можна скопіювати `.env.example` → `.env.local`. Без змінної використовується цей самий production URL (або `VERCEL_URL` на Vercel).

## Архітектура

```
src/app/          маршрути + SEO (metadata, robots, sitemap)
src/components/   UI (practice/, nmt/, спільне)
src/hooks/        usePractice, useNmtHub, useNmtTest
src/redux/        theme, session, results + persist
src/helpers/      checkAnswer, scoring, testGenerator, …
src/constants/    таймери, рейтинг, seo
src/data/         nmtVariants (10×22), practiceTopics, formulas
src/types/        моделі TypeScript
public/           favicon.svg, og.png
```

Правила:

- `app/` тонкий; логіка в `hooks/` і `redux/`.
- Стилі — `Component.module.css` поруч із компонентом.
- Після `setSession` перехід на тест через `persistAndGo` (`flush` → `location.assign`).
- Практика зберігає чернетку в `localStorage` (`nmt-practice-draft`): F5 не зриває активну чи щойно завершену серію (до 7 днів).
- «Завершити тестування» питає підтвердження перед скиданням прогресу.

### Ключові модулі

| Зона | Роль |
| --- | --- |
| `data/nmtVariants.ts` | Генерація 10 авторських варіантів (15+3+4), самоперевірка цілих відповідей |
| `helpers/scoring.ts` | Бали й рейтинг УЦОЯО |
| `helpers/checkAnswer.ts` | Нормалізація коротких відповідей (дроби, π, списки) |
| `hooks/usePractice.ts` | Звичайний / Ultimate (ліміт 20) / помилки, abort до тем |
| `components/practice/TopicBar` | Бейдж режиму, таймер, «Завершити тестування» |
| `constants/seo.ts` | Опис сайту, canonical, OG-хелпери |

## Збереження даних

| Ключ | Що |
| --- | --- |
| `nmt` (persist) | тема, сесія, історія (до 50), статистика тем, поточний результат |
| `nmt-theme` | клас `dark` на `<html>` до гідрації (без FOUC) |
| `nmt-practice-draft` | чернетка практики (активна / завершена серія) до 7 днів |

## Контент банку

- **10 варіантів × 22 = 220** унікальних завдань.
- Повний НМТ бере цілий варіант; практика — усі завдання категорії; Ultimate — випадкові до 20 з теми.
- Завдання авторські (параметризовані), не з копірайтованих збірників Освіта.ua / офіційних буклетів.
