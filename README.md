# НМТ математика — фронтенд

Тренажер [НМТ-2026](https://github.com/tony-kobs/nmt-test-frontend) з математики за структурою Українського центру оцінювання якості освіти (УЦОЯО) і додаткова практика за шкільними темами. Бекенду немає: банк завдань, сесії й історія живуть у браузері.

Головна сторінка — **тренажер НМТ**. Практика — окремий розділ.

- **Тренажер НМТ** (`/`) — повний тест, тренування за категорією, слабкі теми або випадковий варіант. Після здачі — тестові бали, рейтинг 100–200 і розбір помилок.
- **Практика** (`/practice`) — короткі добірки за шкільною темою з миттєвим зеленим/червоним фідбеком.

## Можливості

- Повний НМТ: **22 завдання**, **60 хвилин**, максимум **32 тестові бали**.
- Три типи завдань: одна правильна відповідь, відповідність, коротка відповідь.
- Тренування з фільтром категорії, складності й кількості (10 / 20 / 30).
- Режим «Слабкі теми» будує добірку за статистикою помилок.
- Довідник формул (алгебра / геометрія) з LaTeX через KaTeX.
- Історія спроб, позначка завдання, повтор тесту або одного питання.
- Світла й темна теми у стилі зошита в клітинку.
- Стан зберігається в `localStorage` через Redux Persist (активна сесія і показаний результат завершеного тесту не зникають після оновлення сторінки).

## Оцінювання НМТ-2026

| Тип | Кількість | Бали за завдання | Разом |
| --- | --- | --- | --- |
| Одна відповідь | 15 | 1 | 15 |
| Відповідність | 3 | до 4 | 12 |
| Коротка відповідь | 4 | 2 | 8 |
| **Усього** | **22** | | **32** |

Рейтинг 100–200 рахується лише для повного тесту. Поріг: **5** тестових балів → 100, **32** → 200. Нижче порогу рейтинг не виставляється.

## Стек

Зібрано за підходом GoIT (модулі, хуки, helpers, Redux), адаптовано під Next.js App Router.

| Шар | Бібліотека |
| --- | --- |
| UI | Next.js 16, React 19, TypeScript |
| Стан | Redux Toolkit, redux-persist |
| Форми | Formik + Yup (налаштування тренування НМТ) |
| Стилі | CSS Modules, `clsx` |
| Списки | `react-select` (лише вибір зі списку, без поля вводу) |
| Формули | KaTeX |
| Сповіщення | react-hot-toast |
| Іконки / лоадер | react-icons, react-loader-spinner |
| ID результатів | nanoid |

Axios немає: HTTP-клієнт з’явиться в `src/services/`, коли буде API.

Потрібен Node.js 18+.


## Архітектура

```
src/app/          тонкі маршрути Next.js — майже без логіки
src/components/   UI: кожен компонент у своїй папці
src/hooks/        логіка екранів (практика, хаб, тест)
src/redux/        глобальний стан + persist
src/helpers/      чисті функції: перевірка, бали, генерація тесту
src/constants/    таймер, таблиця рейтингу, ключі сховища
src/data/         банк завдань, теми практики, формули
src/types/        TypeScript-моделі
```

Правила:

- `app/` лише підключає сторінку; логіка — у `hooks/` і `redux/`.
- Стилі — `Component.module.css` поруч із `Component.tsx`.
- `index.ts` у папці компонента реекспортує публічний API.
- Компоненти не пишуть у `localStorage` напряму.
- Після `setSession` перехід на тест іде через `persistAndGo`: спочатку `persistor.flush()`, потім `window.location.assign`.

Брейкпоінти: **320** (мобільний) / **768** (планшет) / **1280** (десктоп). Токени кольорів і `--radius` — у `src/app/globals.css`.

## Збереження даних

| Ключ | Де | Що |
| --- | --- | --- |
| `nmt` | redux-persist | тема, активна сесія, історія, статистика тем, показаний результат завершеного тесту |
| `nmt-theme` | окремий localStorage | клас `dark` на `<html>` до гідрації (без FOUC) |

Старі ключі `nmt-active-session`, `nmt-history`, `nmt-topic-stats` один раз підхоплює `legacyStorage.ts`.

Практика за темами стан у Redux не пише: серія живе лише в `usePractice` до оновлення сторінки.

## UI

- Вигляд зошита: клітинка, Inter, зелений контур «Старт», заокруглені рамки (`--radius: 12px`).
- У шапці дві вкладки: активна — заливка, неактивна — кнопка переходу.
- Темна тема перефарбовує поверхні, рамки, кнопки, селекти, тости й формули — не лише фон.
- Анімації сторінок, кнопок і меню; при `prefers-reduced-motion` майже вимикаються.
- Смуга прокрутки сторінки прихована; контент усе ще можна гортати коліщатком.
